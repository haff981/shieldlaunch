# 🛡️ ShieldLaunch

Solana memecoin launchpad — shieldlaunch.life

gomo 式发币平台：Meteora DBC 联合曲线 + 毕业迁移 DAMM v2 + 发币人分成，
差异化是个人资料页的"我发行的币"。

## 快速开始

```bash
npm install
npm run dev
```

## 文档
- `ARCHITECTURE.md` — 架构、费用流、GMGN 捕捉条件
- `DEVNET_PLAN.md` — devnet 测试步骤（先跑通再谈主网）
- `lib/meteora.ts` — DBC 集成（建 config / 发池 / 领费）
- `lib/constants.ts` — 费钱包、程序 ID、config 地址
